# Social Media Checklist: Lembar Periksa Konten Sosial

- [ ] **Bebas Kebun Emoji**: Maksimal 0–2 emoji di seluruh unggahan.
- [ ] **Bebas Hook Murahan**: Tidak menggunakan format clickbait bot (*"99% orang tidak tahu..."*).
- [ ] **Bebas Em-Dash Berlebihan**: Menggunakan ritme kalimat pendek tanpa tanda pisah teatrikal.
- [ ] **Bebas Mengemis Interaksi**: Berhenti tanpa kalimat *"Ketik MAU di komentar"* atau *"Retweet jika setuju!"*.
