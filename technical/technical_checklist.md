# Technical Checklist: Lembar Periksa Respon Teknis

- [ ] **Bebas Sejarah Teori**: Langsung menyajikan akar masalah tanpa pengantar panjang.
- [ ] **Kode Dapat Dijalankan Langsung**: Kode lengkap dengan import/penanganan error, bukan potongan kosong (*// TODO*).
- [ ] **Ada Perintah Verifikasi**: Menyertakan langkah konfirmasi bahwa perbaikan berhasil.
- [ ] **Komentar Menjelaskan Alasan**: Komentar baris menjelaskan mitigasi risiko, bukan sintaks visual.
